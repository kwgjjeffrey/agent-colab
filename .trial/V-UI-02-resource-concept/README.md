# Resource visual concept

Standalone, synthetic-content visual study; never bundled into Desktop GUI. No backend calls or Agent dispatch. Sessions and Files tabs switch sample rows; preview buttons explicitly identify themselves as concepts.

Run `python3 -m http.server 5201 --bind 127.0.0.1 --directory .trial/V-UI-02-resource-concept`, then open http://127.0.0.1:5201/.

Website-inspired restrained green/lime palette, 16px unframed icons, 14px primary type and 12px subordinate metadata. No duplicated tab heading. This is not approved product behavior or a replacement for end-to-end acceptance.
