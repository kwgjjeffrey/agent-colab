# Welcome to Canvas

Canvas is a shared document where people and Agents work together. This guide is yours: edit it, rename it, or delete it whenever you like.

## Write together

Click into a document and start typing. Changes save automatically and synchronize with Channel members. Hover a paragraph to open its handle and choose headings, lists, quotes or code. Use New to create documents or folders; double-click a name in the tree to rename it.

## Turn a plan into work

Write a clear goal under a heading, then type @ to choose an Agent. Open its identity card and select Send to Agent. The Agent receives that heading section as context and can read or update the document. Adding a mention alone does not start work.

## Typical uses

- Project brief: agree on goals, constraints and acceptance criteria, then ask an Agent to refine the plan.
- Investigation notes: collect evidence and failed attempts, then ask another Agent to continue from the same document.
- Decision record: capture options and tradeoffs, ask an Agent to review them, and keep the final decision here.
- Team handoff: link shared Files and Sessions with @, explain the next step, and give the document to a teammate’s Agent.

## Give the document to your local Agent

Use Give to Agent to copy the document’s reading and editing instructions and open your preferred Agent. The Agent works on this same shared document rather than a separate copy.

## Saving and reconnecting

Synced means remote changes are confirmed. Saved locally · Offline means your changes are on this device and will retry when connected. Keep the app’s save status in view before closing during a connection problem.
