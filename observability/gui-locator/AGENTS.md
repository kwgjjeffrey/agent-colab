# Colab GUI locator adapter

This project-owned adapter connects the generic Trace catalog to the installed Colab GUI. It is not a second operation catalog. Load unit registries through the repository index; DOM bindings and spans use the same IDs. Keep provider credentials out of browser responses. The protected discovery file stays on the proxy side. Preserve HTTP and WebSocket origin guards.

Inspection may click marked navigation controls and tabs, never business targets. Distinguish visible controls, owning display regions and unavailable prerequisites. Tests must cover the formal catalog's returned URL and real installed GUI highlighting, not only marker counts. No production startup or tests may depend on `.trial`.

Do not restore a project-owned highlighting engine. Import the installed standard module from observability/page-locator; keep the bootstrap limited to diagnostic activation, origins and live operations. Tests consume that installed module, not a copied legacy implementation.
